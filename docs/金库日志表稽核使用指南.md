## 三、特殊说明

### 1. 唯一性核查
金库日志表的唯一性核查使用**组合键**：
```
gold_grant_result + resource_pool + gold_exec_result + approved_user_name
```

### 2. 条件非空核查
某些字段只在特定条件下必填：

**start_time / end_time**：
- 条件：`gold_grant_type = '按时间段'`
- 说明：只有按时间段授权时，开始和结束时间才必填

**approved_user_id**：
- 条件：`gold_grant_type != '按时间段' AND gold_exec_result NOT IN ('审批不通过', '未触发金库')`
- 说明：非按时间段且审批通过时，审批人ID必填

**approved_user_name**：
- 条件：`gold_grant_type != '按时间段' AND gold_exec_result NOT IN ('未触发金库')`
- 说明：非按时间段且触发金库时，审批人姓名必填

**gold_scene_name**：
- 条件：`gold_exec_result != '未触发金库'`
- 说明：触发金库时，场景名称必填

### 3. 测试数据过滤
所有查询都会自动过滤测试数据：
```sql
WHERE standby1 IS NULL
```

## 四、与操作日志表的区别

| 特性 | 操作日志表 | 金库日志表 |
|------|-----------|-----------|
| 主键 | `log_id` | `gold_grant_result`（组合键） |
| 分组字段 | `dst_device_type` | 无（不分组） |
| 测试数据过滤 | 无 | `standby1 IS NULL` |
| 条件非空核查 | 少量 | 较多（4个字段） |
| 特殊字段 | 操作相关 | 审批相关 |

## 八、常见问题

### Q1: 如何同时稽核操作日志和金库日志？
```bash
python3 main.py --table operation_log,gold_log
```

### Q2: 如何只稽核某几个字段？
编辑 `config/tables/gold_log.yaml`，注释掉不需要的字段：
```yaml
audit_tasks:
  - field: gold_grant_result
    checks:
      - uniqueness_check
  
  # - field: resource_pool  # 注释掉不稽核的字段
  #   checks:
  #     - null_check
```

### Q3: 条件非空核查的条件在哪里配置？
在 `config/tables/gold_log.yaml` 中的 `condition` 字段：
```yaml
- field: start_time
  checks:
    - conditional_null_check
  condition: "gold_grant_type = '按时间段'"  # 这里配置条件
```

### Q4: 如何修改唯一性核查的组合键？
编辑 `sql_templates/gold_log/uniqueness_check_stats.sql`，修改组合键逻辑：
```sql
gold_grant_result || '+' || resource_pool || '+' || gold_exec_result || '+' || approved_user_name
```
